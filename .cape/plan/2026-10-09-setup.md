# harmonize repository naming across github organization

Repository names across `radical-transparency-net` must follow a functional taxonomy (see `.cape/context/2026-10-09-github-ecosystem.md`):
- Standalone tools take a `-tool` suffix:
  - `wrx` $\rightarrow$ `wrx-tool`
  - `webmap-ER` $\rightarrow$ `webmap-er-tool`
- Reference demonstrators and testbeds take a `docker-` prefix and `-demo` suffix:
  - `lod_docker_webserver` $\rightarrow$ `docker-rt-patterns-demo`

The renames will be scheduled and executed deliberately to allow updating CI pipelines and documentation links without breakage.
