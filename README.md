# Radical Transparency Network (`radical-transparency-net.github.io`)

> **The Gateway into the Radical Transparency (RT) Ecosystem**  
> Operationalizing open science semantic interoperability, machine-actionable provenance, and web-scale linked data federation.

---

## 🌐 Overview

This repository hosts the emerging public landing portal and entrypoint for the **Radical Transparency Network** (`https://radical-transparency.net`).

The project is currently in an active prototyping and alignment phase. The core ideas, architectural narratives, and community tracks (spanning conceptual foundations, developer tools, validator testbeds, and institutional playbooks) are being co-created and refined across the team.

---

## 🚀 Quick Start

### Prerequisites
* **Node.js** (v18.0.0 or later, v20+ recommended)
* **npm** (v9.0.0 or later)

```bash
# 1. Install dependencies
npm install

# 2. Start local development server (http://localhost:5173)
npm run dev

# 3. Build and validate production bundle
npm run build
```
